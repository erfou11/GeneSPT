# Lightweight Protocol A source data

This Git-tracked subset contains the current formal benchmark summaries,
Supplementary Tables S1-S3 support, and plotting source for Figures 2-6.

The data archive contains the complete counterpart, including compact
prediction/truth matrices, full gene-level metrics, readout locks and the large
Figure 6 effect table.

All files in this directory belong to the v1.0.0 benchmark release:
GeneSPT uses the validation-selected readout and the six external methods use
raw identity output.

The Git-tracked benchmark summaries, Figure 2 source, Figure 4 source and
Supplementary Table S2 include stAI. Figure 5's full per-gene source table is
about 64 MB and is distributed through Zenodo; its caption and
source manifest are tracked here.
