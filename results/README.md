# Results Directory

Local predictions, checkpoints, and evaluation outputs are written here.
Generated outputs are ignored by Git and archived on Zenodo when needed.

`source_data/` is the exception for lightweight reviewer-facing tables.
`source_data/protocol_a/` contains benchmark summaries and compact
Figure 2/4/S2 support, including stAI; the approximately 64 MB Figure 5
per-gene source remains in the reviewer archive. `source_data/figure6/`
retains only the frozen downstream provenance for the current Figure 6
version. Large prediction matrices and the approximately 80 MB consolidated
Figure 6 Panels B-C source table are not tracked here.
